# Sécurité

Argos est en préversion ; seule la dernière version publiée reçoit les correctifs de
sécurité dans la mesure des disponibilités des responsables.

Pour signaler une vulnérabilité, utilisez le bouton **Report a vulnerability** dans
l'onglet [Security](https://github.com/NeKeR53/Argos/security/advisories/new) du dépôt.
Décrivez les versions concernées, les étapes de reproduction et l'impact, sans inclure
de secrets réels. Ne publiez pas de détails exploitables dans une issue publique avant
qu'un correctif ait pu être préparé. Les responsables examineront le signalement sans
garantie de délai.

Les agents peuvent exécuter des commandes avec les droits configurés et utiliser les
services d'IA auxquels vous les connectez. Protégez vos jetons, vérifiez les outils
autorisés et ne connectez que des services et espaces de travail de confiance.
