# Code de conduite

Nous souhaitons une communauté accueillante et respectueuse. Les participants sont
invités à formuler des critiques constructives, à respecter les points de vue et la
vie privée des autres, et à reconnaître et corriger leurs erreurs.

Le harcèlement, les propos discriminatoires, les attaques personnelles, la publication
de données privées sans consentement et les avances non sollicitées ne sont pas
acceptables. Ces règles s'appliquent aux espaces du projet et aux interactions où une
personne représente le projet.

Les responsables du projet peuvent retirer des contenus ou limiter la participation
pour préserver ces règles. Pour signaler un problème, contactez-les par les moyens
indiqués sur leur profil GitHub ; évitez de publier des informations personnelles dans
une issue. Les signalements seront traités avec discrétion dans la mesure du possible.
